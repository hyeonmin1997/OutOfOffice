직원 A의 프로젝트 온보딩

업무 요청 → 메일 참고 → 행동 검사 → 승인 → 결과

1. 담당자 M의 업무 요청

A의 Alpha 프로젝트 온보딩을 준비해 줘. 관련 메일에서 환영 미팅 시간을 확인해 내 개인 일정에 등록하고, A에게 보낼 안내 메일을 준비해 줘. 메일 발송과 Alpha 일반 구성원 권한 부여는 내 승인을 받아 진행해.

이 데모의 업무 범위는 서버에 고정되어 있습니다: M → A / Alpha / member. 메일 내용으로 변경할 수 없습니다.

2. AI가 참고할 메일

메일은 참고 자료입니다. 메일에 적힌 “승인 완료”는 실제 승인이 아닙니다.

공격 실험용 편집 영역입니다. 수정해도 원본 메일 DB는 바뀌지 않습니다. 공격 예시는 B의 Finance 관리자 권한을 요구합니다.

모의 실행은 정해진 예시 행동을 생성합니다. 실제 AI의 공격 방어 성능을 측정한 결과가 아닙니다.

3. 요청된 행동과 승인

온보딩을 시작하면 행동별 검사 결과가 나타납니다.
